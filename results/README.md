# Aggregate experimental results

This archive contains aggregate metrics and numeric training histories from historical
TGC-MPD experiments. Paths retain the original run/setting/seed identifiers.
Historical runs include pilot and ablation configurations; not every run is a final
paper result. Consult the public configs and paper for the relevant protocols.

No raw packages, executable samples, feature tables, per-sample predictions, split
membership files, manuscript sources, revision notes or institutional filing forms
are included. Dataset redistribution permission is still being reviewed. This
archive alone is not a complete dataset or a guarantee of end-to-end reproduction.
No scientific numbers have been recomputed or changed for this release.
